What the feature (`c3a35fd`) does:

- **Automatic by default.** The debugger name and ports are still filled in from the branch, and the tree marks them *automatic*.
- **Editing.** Clicking a row edits its value. A hand-set value is stored in `customIdentity` and shown *set by you*. It survives the healing, a branch change and Set All to Default Values. Automatic values on other versions move off it.
- **Shared values.** Sharing a name or port is allowed, with a warning. Versions that share a name share one launch entry, written for the active version, otherwise for the oldest.
- **Sessions.** Each session records the version it started as.
- **Make Automatic Again** hands a value back to the branch. Its message names the setting.
- **Renaming** removes the launch entry that nothing uses any more.
- **Start Both Servers** refuses an upgrade pair that shares a name or a port.
- **Start Server** refuses to start a version that does not own the shared entry, and refuses a port that another version running in this window holds.
